Wrap key names in braces to press them:
{Enter} {Esc} {Tab} {Space} {Backspace} {Up} {Down} {Left} {Right} {F1}–{F12}
Add modifiers with +: {Shift+Tab} {Ctrl+C}
Type the clipboard text with {Clipboard}, for example explain this error: {Clipboard}. Line breaks in the clipboard text are entered as Ctrl+J, and long text is cut to 10,000 characters.
Type a literal brace with {{ or }}.
